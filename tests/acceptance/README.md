# acceptance — the product's built-in acceptance suite

Self-contained, deterministic, user-level acceptance of the Growable
Soft Model product (clean-room rewrite of the project's historical
acceptance campaigns, renamed and retargeted at the current system —
no external directories, tools, or benchmarks required).

  A. Generator acceptance  (tests/acceptance/phase1_generator.py)
     birth/self-shaping, reality-gated teaching (garbage rejected),
     rollback, drift detect -> re-teach -> gate clears, discovery of a
     hidden categorical rule, extrapolation probe (reported).
  B. Growth acceptance     (tests/acceptance/phase2_growth.py)
     curriculum-forced multi-scale growth via the automatic course
     runner: committed growth events, structure deepens, lineage
     auditable.
  C. System acceptance     (tests/acceptance/phase3_system.py)
     total-plasticity verbs end-to-end (widen / add_feature / refound
     with the commit gate in charge) and a granted self-study session
     under the consent rules (C1-C6).

Run everything:   python3 tests/acceptance/run_acceptance.py
(exit 0 = all acceptance criteria pass; a pass/fail table prints per
criterion. Public-model comparisons are research campaigns, not
product acceptance and are recorded in the development
repository.)
